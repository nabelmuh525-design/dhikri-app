# ذِكري | DHIKRI — تطبيق إسلامي متكامل (Android)

مشروع Android مستقل مبني بالكامل من الصفر باستخدام:
- **Kotlin 2.0 + Jetpack Compose + Material 3**
- **Clean Architecture + MVVM**
- **Room Database** (قاعدة بيانات محلية مدمجة `dhikri_database.db` تعمل أوفلاين من أول تثبيت)
- **Navigation Compose + Android Predictive Back Gesture** (`android:enableOnBackInvokedCallback="true"`)
- **DataStore Preferences + WorkManager**

## التحقق من البيانات المدمجة
- **السور**: 114 سورة
- **الآيات**: 6,236 آية (بنص حفص العثماني المتوافق مع `Hafs_20.ttf` + نص Tanzil v1.1 الحرفي + فهرس بحث عربي مطبّع)
- **الصفحات**: 604 صفحة
- **الأجزاء / الأحزاب / الأرباع**: 30 جزءاً، 60 حزباً، 240 ربع حزب
- **السجدات**: 15 موضع سجدة (4 واجبة + 11 مستحبة)
- **الأذكار والأدعية**: 134 باباً (285 ذكراً ودعاءً من حصن المسلم + الأدعية القرآنية وأدعية الأنبياء)
- **الحكايات الإسلامية**: قصص موثقة مع فصل النص القرآني عن السرد التوضيحي
- **السبحة الإلكترونية**: عداد تفاعلي، تسبيحات جاهزة ومخصصة، اهتزاز وصوت اختياري، سجل يومي واستعادة آخر جلسة

## طريقة بناء ملف APK عبر GitHub Actions (للمبتدئين)
1. أنشئ مستودعاً جديداً على GitHub (مثلاً `dhikri-app`) وفك ضغط ملف `dhikri-android-project.zip` على جهازك.
2. ارفع جميع الملفات والمجلدات إلى المستودع عبر خيار **Add file → Upload files**.
3. **ملاحظة مهمة لمستخدمي المتصفح**: الرفع بالسحب والإفلات يتجاهل المجلدات المخفية التي تبدأ بنقطة مثل `.github`. لذلك بعد رفع الملفات:
   - افتح تبويب **Actions** في المستودع.
   - اضغط **set up a workflow yourself**.
   - انسخ محتوى ملف `GITHUB_ACTIONS_WORKFLOW.yml` الموجود في المشروع والصقه هناك، ثم اضغط **Commit changes**.
4. سيعمل البناء السحابي تلقائياً: يقوم بسحب **التفسير الميسر** و**السراج في بيان غريب القرآن** رسمياً من QuranEnc ودمجهما داخل قاعدة البيانات، ثم يشغّل اختبارات الوحدة، ثم يبني ملف **Release APK**.
5. بعد ظهور علامة الصح الخضراء، افتح التشغيل ونزّل ملف **`DHIKRI-Release-APK`** من قسم **Artifacts** وثبّته على هاتفك الأندرويد.
